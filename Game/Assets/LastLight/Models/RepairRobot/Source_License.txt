   DESCRIPTION
-----------------

  "Spid-B Bot" is a fully rigged spider robot with facial movements, designed for animation in Blender.
  This package also includes a .obj,.glb, and .fbx versions with a basic rig for easy import.
  You’re free to use or modify this asset in any way you like — credit is not required but always
  appreciated.  
  
  Thank you very much for your support!
  
------------
   UPDATE   
------------

Spid-B Bot 2.0 now has:
  - Improved geometry and UV maps.
  - New 4K texture.
  - Improved rig with new facial movement bones.
  - New functional color switch system working in both Cycles and Eevee.
  - A custom color editor.
  - Improved IK/FK switching.
